# 高等数学 · 第三章 导数与微分

## 导数公式与运算法则

> 来源：考研数学全面基础课·高等数学（上）第 3 讲 导数常规计算

### 常见函数的导数总结

| $f(x)$ | $f'(x)$ |
| --- | --- |
| $c$（$c$ 为常数） | $0$ |
| $x^{\alpha}$ | $\alpha x^{\alpha-1}$ |
| $\mathrm{e}^{x}$ | $\mathrm{e}^{x}$ |
| $a^{x}\ (a>0)$ | $a^{x}\ln a$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\log_a x\ (a>0,\ a\ne1)$ | $\dfrac{1}{x\ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^{2}x$ |
| $\cot x$ | $-\csc^{2}x$ |
| $\sec x$ | $\sec x\tan x$ |
| $\csc x$ | $-\csc x\cot x$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^{2}}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^{2}}$ |
| $\arccos x$（补充） | $-\dfrac{1}{\sqrt{1-x^{2}}}$ |
| $\operatorname{arccot}x$（补充） | $-\dfrac{1}{1+x^{2}}$ |

> 表中最后两行为原讲义未列出、但考试常用的**补充公式**，与 $\arcsin x$、$\arctan x$ 的导数只差一个负号。

**记忆**：

- $\sin\leftrightarrow\cos$ 互为导数（$\cos$ 带负号），$\tan,\cot,\sec,\csc$ 四个记住 $\tan x\to\sec^{2}x$、$\cot x\to-\csc^{2}x$ 即可；
- 反三角"三个 $1$ 打头"：$\arcsin x,\arccos x$ 的导数含 $\sqrt{1-x^{2}}$，$\arctan x,\operatorname{arccot}x$ 的导数含 $1+x^{2}$；$\arcsin x,\arctan x$ 为正，$\arccos x,\operatorname{arccot}x$ 为负。

### 导数四则运算法则

如果函数 $f(x)$ 与 $g(x)$ 各自存在导数，则有

$$
[f(x)\pm g(x)]'=f'(x)\pm g'(x)
$$

$$
[f(x)\cdot g(x)]'=f'(x)\cdot g(x)+f(x)\cdot g'(x)
$$

$$
\left[\frac{f(x)}{g(x)}\right]'=\frac{f'(x)g(x)-f(x)g'(x)}{g^{2}(x)}\qquad (g(x)\ne0)
$$

**记忆**：乘积法则"前导后不导 + 前不导后导"；商法则分子是"**上导下不导 − 上不导下导**"（顺序不能颠倒），分母为原分母的平方。

**易错点**：

- $[f(x)g(x)]'\ne f'(x)g'(x)$，乘积求导**不能**逐项相乘；
- 商法则分子中两项的**相减顺序**固定，写反会整体变号；
- 和差法则可以推广到任意有限多项，乘积法则推广到 $n$ 项时是"逐项求导再相加"；
- 使用前提是 $f,g$ 在**同一点**处各自可导。
