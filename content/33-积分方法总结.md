# 高等数学 · 第六章 不定积分

## 积分方法总结

> 出处：第 6 讲末尾「积分方法总结」表。**做题前的第一张检查清单。**

| 方法 | 题目特点 | 方法原理 |
| --- | --- | --- |
| **基本原函数公式** | 常见函数的原函数，不需要其他计算步骤，但需**格外熟练掌握** | 略（见 [[27-基本积分表]]） |
| **$(ax+b)$ 的线性变化** | $f(ax+b)$ 的形式。例如 $\displaystyle\int\frac{1}{3x+2}\,\mathrm{d}x$ | 把 $(ax+b)$ 当作整体，直接求出原函数后再**整体除以 $a$** |
| **凑微分法** | 一部分是另一部分的导数。例如 $\displaystyle\int\frac{\sin x}{\cos x}\mathrm{d}x$、$\displaystyle\int\frac{\ln x}{x}\mathrm{d}x$、$\displaystyle\int\frac{\arctan x}{1+x^{2}}\mathrm{d}x$ | $\displaystyle\int f(u)u'\,\mathrm{d}x=\int f(u)\,\mathrm{d}u$ |
| **根号整体代换** | 含 $\sqrt{ax+b}$ 等类型的根式。例如 $\displaystyle\int\frac{1}{1+\sqrt{2x+1}}\mathrm{d}x$、$\displaystyle\int\frac{1}{\sqrt{\mathrm{e}^{x}+1}}\mathrm{d}x$ | 令 $t=\sqrt{\ast\ast\ast}$（题目中的根号） |
| **三角代换** | 含 $\sqrt{ax^{2}+bx+c}$。例如 $\displaystyle\int\frac{\mathrm{d}x}{x^{2}\sqrt{1+x^{2}}}$、$\displaystyle\int\sqrt{x^{2}+2x+2}\,\mathrm{d}x$ | 利用勾股定理画出相匹配的直角三角形，用三角函数来积分 |
| **分部积分法** | 被积函数中同时出现了**不同类型**的函数。例如 $\displaystyle\int x\sin x\,\mathrm{d}x$、$\displaystyle\int\mathrm{e}^{x}\sin x\,\mathrm{d}x$ | $\displaystyle\int u\,\mathrm{d}v=uv-\int v\,\mathrm{d}u$，"反对幂指三" |
| **特定类型**（有理分式） | 有理分式 | 假分式化真分式、分母的因式分解 |
| **特定类型**（三角有理式） | 三角有理式 | 凑导数法则、万能代换 |

### 做题判断流程

1. **能不能直接查表？** —— 基本原函数公式 + $(ax+b)$ 线性变化。
2. **能不能凑微分？** —— 找"一部分是另一部分的导数"。
3. **有没有根号？**
   - 根号内是 $x$ 的**一次**式 → 根号整体代换（[[31-第二类换元法]]）
   - 根号内是 $x$ 的**二次**式 → 三角代换（[[31-第二类换元法]]）
4. **是不是两类不同函数相乘？** —— 分部积分（[[32-分部积分法]]）。
5. **是不是特定类型？** —— 有理分式（[[29-有理分式积分]]）、三角有理式（[[30-三角有理式积分]]）。

> 顺序只是**优先级**，不是铁律。例如 $\displaystyle\int\frac{\ln x}{x}\mathrm{d}x$ 既可凑微分也可分部积分，但凑微分快得多；$\displaystyle\int\frac{\mathrm{d}x}{x^{2}\sqrt{1+x^{2}}}$ 既可用三角代换，也可倒代换。

### 各方法的"信号词"

| 看到什么 | 立刻想到 |
| --- | --- |
| $f'(x)$ 与 $f(x)$ 同时出现 | 凑微分 |
| $\sqrt{ax+b}$ | 令 $t=\sqrt{ax+b}$ |
| $\sqrt{a^{2}-x^{2}}$ | $x=a\sin t$ |
| $\sqrt{a^{2}+x^{2}}$ | $x=a\tan t$ |
| $\sqrt{x^{2}-a^{2}}$ | $x=a\sec t$ |
| 多项式 × $\mathrm{e}^{x}/\sin x$ | 表格分部积分 |
| 多项式 × $\ln x/\arctan x$ | 分部积分（对数、反三角作 $u$） |
| $\mathrm{e}^{x}\sin x$ | 分部积分循环两次 |
| 有理分式 | 假分式化真分式 + 部分分式 |
| $R(\sin x,\cos x)$ | 三条凑微分，否则万能代换 |
| 分母次数远高于分子 | 倒代换 $t=\frac1x$ |

### 易错点

- 五步走完还做不出来时，先检查**是否有代数变形**（分子加减一项、上下同除 $x^{2}$、配方、拆项）—— 多数"想不到"的题都卡在这一步，而不是卡在方法上。
- **不要一上来就用万能代换或三角代换**：它们一定可行但最慢，属于"保底方案"。
- **每换一种方法都要重新检查 $C$ 和回代**，特别是第二类换元法。
- 积分结果**必须求导验证一次**（尤其考场时间紧时至少检查符号），这是最可靠的自我纠错手段。
