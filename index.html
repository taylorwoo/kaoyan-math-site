使用说明

  1. 配套题目：题目与解答放在知识点下方的折叠框中，点击标题可展开或收起。从大纲、搜索或收藏跳转时，会自动展开题框。
  2. 划重点：用鼠标选择一段文字，浮动工具条可以标黄、蓝、粉三种颜色；再选中已标记的文字，可取消重点。
  3. 公式与跨段内容：选中含公式的内容时，使用“整段重点”；也可直接点击段落旁的标记按钮。
  4. 收藏与批注：每段旁边的星号用于收藏，铅笔用于批注。“我的标记”可筛选查看，并返回原文。
  5. 保存与备份：重点、收藏、批注和阅读位置默认保存在当前浏览器。请固定使用同一浏览器访问同一个网站地址；换设备或清理浏览器数据前，用“导出标记”保存JSON备份，之后可以导入恢复。
  6. 网站读取：笔记自动从网站加载。修改 HTML、MD 或图片后，在 GitHub 提交上传，等待 Cloudflare 部署成功，再刷新网页。查看中文操作说明。
  7. 快捷操作：Ctrl / ⌘ + K 搜索，Ctrl / ⌘ + Z 撤销标记。手机可用侧边按钮进行整段标记和收藏。

原书的疑似错误保留在正文中，单独列于“原书疑点待确认”，没有擅自修改结论。
